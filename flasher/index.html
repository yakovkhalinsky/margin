  • Hold the Power button during flashing (the bootloader doesn't latch power)

📱 Bootloader Mode

If flashing fails, you may need to put the X4 Pro into bootloader/download mode:

  1. Power off the device completely
  2. Connect the pogo-pin USB dongle
  3. Hold the Boot button (if available) while connecting power
  4. Release after 2 seconds — the device should appear as a serial port
  5. If there's no dedicated Boot button, try holding Volume Down + Power

The device should enumerate as /dev/ttyACM0 (Linux) or COM3 (Windows).

📖 Setting Up Bible Mode

The Bible text is stored on the SD card, not in the firmware. After flashing margin:

  1. Generate the Bible data: 
    python tools/bsb-converter.py --output ./bible-data/
  2. Copy the margin/bible/ folder to your SD card root
  3. Insert the SD card and open Bible mode from the menu

See docs/bible-mode.md and tools/bsb-converter.py for details.

🔧 Technical Details

Flash Layout (ESP32-S3, 16 MB)

Component Offset Size
Bootloader 0x0 ~24 KB
Partition Table 0x8000 3 KB
OTA Data 0xe000 8 KB
Application (app0) 0x10000 ~6.25 MB
Application (app1/OTA) 0x650000 ~6.25 MB
SPIFFS 0xc90000 ~3.4 MB
Coredump 0xff0000 64 KB

Offsets verified against CrossPoint's partitions.csv and ESP-IDF documentation. The merged binary includes bootloader, partition table, and application at their correct offsets.

⚠️ Risk Warning

Flashing third-party firmware may void your warranty. Always back up before flashing. If something goes wrong, you can restore your backup with:
esptool.py write_flash 0 backup.bin
